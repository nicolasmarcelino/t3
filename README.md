# Problema F
[Codeforces 449B Jzzhu and Cities (caminho mínimo)]()

_Resumo: dado um país com cidades conectadas por estradas e rotas de trem saindo da capital, deseja-se fechar o máximo de rotas de trem sem alterar a distância mínima da capital até qualquer cidade. Uma rota de trem só precisa ser mantida se ela for indispensável para atingir essa distância mínima, ou seja, se for mais curta que qualquer caminho por estradas, ou se for igual a ele e não houver outro caminho (por estrada) de mesmo comprimento. Para cada cidade, no máximo uma rota de trem precisa ser mantida._
